# Intelligent Agents e-portfolio

Lyth Hishmeh (34119) · IA_PCOM7E Intelligent Agents, University of Essex Online

This repository holds the Intelligent Agents section of my e-portfolio. It is best read as the published GitHub Pages site, which opens on `index.md`.

## Contents

- `index.md` is the landing page. It links to every item and maps the evidence to the module
  learning outcomes.
- `collaborative_discussions/` holds my initial post and two peer responses for each of the three
  discussions, the text of all nine posts with their forum addresses in `forum_posts.md`, and
  screenshots of the posts on the module forum.
- `unit_activities/` holds the Unit 6 agent dialogue, the Unit 8 parse trees and the Unit 10
  deep-learning application, with the code in `code/` and its outputs in `outputs/`.
- `project_evaluations/` holds my evaluations of the development project at Units 7 and 11.
- `development_project/` holds the design report, the project report, their figures, and the
  complete chatbot source with its tests and tool output.
- `reflection/` holds the reflective piece, as a web page and as the Word document.

## Running the code

The unit-activity scripts need Python 3.11 or later; `parse_trees.py` also needs matplotlib.
The chatbot has its own README in `development_project/chatbot/` covering setup, seeding,
running and testing. It runs fully without an API key, using its rule-based interpreter.
The key file and the generated database are not part of this repository.
