# Development project: UniBot

The student-services chatbot designed for the team project and built for the individual project.

- [Design report](design_report/34119_IA_PCOM7E_Development_Team_Project_Design_Report.docx) (Assignment 1), as submitted.
- [Project report](project_report/34119_IA_PCOM7E_Development_Individual_Project_Report.docx) (Assignment 2), as submitted.
- `figures/` — architecture, message-sequence and evaluation figures used in the reports.
- `chatbot/` — full source: the `unibot` package, tests, evaluation scripts, screenshots and the raw
  tool output in `chatbot/evidence/`. [chatbot/README.md](chatbot/README.md) explains how to seed and
  run it; the secrets file and generated database are not included.

The design applies agent architectures and an agent communication language to a real service problem;
the implementation deploys and evaluates them with functional, security and static testing. The
[Unit 7](../project_evaluations/unit7_team_project_evaluation.md) and
[Unit 11](../project_evaluations/unit11_individual_project_evaluation.md) evaluations reflect on both.
